# Small Language Model (SLM) Implementation 🚀

This repository contains the implementation of a Small Language Model (SLM), developed as part of a team project. This project was recognized with an award for its performance and implementation logic.

## 🏆 Achievements
* **Team Lead:** Managed a team of 5 to design and implement the model.
* **Prize Winner:** Received a monetary award and certificate from the project mentor for excellence in SLM development.

## 🛠️ Tech Stack
* **Language:** Python
* **Environment:** Google Colab (GPU)
* **Libraries:** PyTorch, Transformers (HuggingFace), NumPy, Datasets

## ✨ Key Features
* **Efficient Architecture:** Optimized for lower computational resources while maintaining high text-generation quality.
* **Custom Training:** Fine-tuned on specific datasets to improve context awareness.
* **Tokenization:** Implemented specialized tokenization to handle unique data structures.

## 📂 Project Structure
* `SLM_Notebook.ipynb`: The primary notebook containing the model architecture, training loops, and evaluation.
* `Sample_Results/`: (Optional) Directory containing generated output samples.
